# India ITR Filing SaaS

This repository contains the implementation plan for an AI-assisted Indian income-tax return filing workspace for individual taxpayers.

The launch contract is export-first: the product extracts evidence-linked facts from taxpayer documents, applies deterministic and versioned tax rules, validates an official-format return, and guides manual filing when authorized government submission is unavailable. It must never claim a return was filed without confirmed authorized submission.

- [Technical implementation plan](plans/2026-10-12-1200-brainstorm-itr-filing-saas-plan.md)
